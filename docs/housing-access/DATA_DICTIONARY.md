# Data Dictionary

## `access_time_series.csv`

| Field | Meaning |
|---|---|
| `domain` | One of six Version 1.2 evidence domains. |
| `metric_id` | Stable machine-readable measure identifier. |
| `metric_name` | Public label. |
| `county_fips`, `county_name` | Configured county identity. |
| `period`, `period_end` | Source-native period and sortable end date. |
| `frequency` | Source cadence and estimate type. |
| `value`, `unit` | Numeric observation and unit. |
| `margin_of_error` | Published ACS margin of error when available. |
| `source_ids` | Semicolon-delimited source identifiers. |
| `source_releases` | Releases aligned with `source_ids`. |
| `raw_sha256s` | Snapshot hashes aligned with `source_ids`. |
| `calculation` | Published value or explicit derivation. |
| `notes` | Definition and interpretation constraints. |
| `comparability_status` | Machine-readable timing or count-design warning. |

## Supporting exports

- `access_snapshot.csv`: latest observation per county and metric.
- `income_progress.csv`: permits, target, and recomputed progress by income category.
- `pit_count_types.csv`: CoC mapping and full-versus-sheltered-only status.
- `source_freshness.csv`: cadence, latest evidence, retrieval time, and snapshot count.
- `source_snapshots.csv`: raw paths and upstream hashes, generated by the live build.
- `quality_checks.csv`: build-time gates; zero failed rows are permitted.

The complete metric catalog is `metadata/housing_access_indicator_catalog.csv`.
