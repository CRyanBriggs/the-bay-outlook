# Housing Access & Displacement — Version 1.2

This release extends The Bay Outlook Housing Observatory with six access-focused
domains for the nine-county San Francisco Bay Area.

## Included evidence

- Eleven fiscal years of limited civil unlawful-detainer court cases.
- Separate severe rent-burden, overcrowding, and rent-pressure components.
- Four PIT/HIC cycles with HUD count type retained for every county-year.
- 2023–2025 HCD permits and sixth-cycle RHNA allocations by income category.
- Four annual HUD-assisted-housing county snapshots.
- ACS worker earnings and FY2026 one- and two-bedroom HUD FMR benchmarks.

The public repository contains selected verified snapshot exports. Running the
documented build regenerates the normalized time series, raw-evidence register,
public JSON, and SQLite warehouse.

## Evidence boundary

This is a descriptive evidence product. It does not infer why a county changed,
predict displacement, measure executed evictions, or rank counties. New
narrative analysis still requires named-human approval.
