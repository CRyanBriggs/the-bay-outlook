# Housing Observatory Limitations

- ACS values are five-year pooled estimates. Adjacent releases share survey
  years and should not be read as independent annual samples.
- ACS rent and home value describe occupied housing and owner-reported values;
  they are not asking rents or transaction prices.
- Ratios of county medians do not represent any particular household and omit
  mortgage rates, taxes, insurance, down payments, and within-county variation.
- Redfin data are a documented private primary-market source, not a government
  statistic. Coverage and historical values may be revised.
- A building permit authorizes construction; it does not establish that a unit
  was started, completed, occupied, or affordable.
- Census BPS and HCD APR are related but not interchangeable. BPS is a federal
  permit survey; APR contains jurisdiction-reported housing-element progress.
- RHNA allocations are planning targets, not forecasts. The progress ratio uses
  2023–2025 APR permits and does not imply the planning period is complete.
- County aggregation can conceal large differences among cities,
  unincorporated areas, housing types, and income groups.
- Release calendars differ, so the latest values do not all describe the same
  point in time.

These constraints are shown in the public interface and should accompany any
new analysis derived from the data.
