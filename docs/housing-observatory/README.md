# Version 1.1 Housing Observatory

The Housing Observatory is the first post-MVP subject expansion of The Bay
Outlook. It covers seven housing domains across all nine Bay Area counties and
keeps each public value linked to a documented release and reproducible raw
snapshot.

## Public products

- Interactive observatory: https://the-bay-outlook.kw5f4w8d9g.chatgpt.site/housing
- Published latest values: `data/housing/housing_snapshot.csv`
- Published RHNA progress: `data/housing/rhna_progress.csv`
- Published source health: `data/housing/source_freshness.csv`
- Live-build outputs: `data/phase14/exports/`, `data/phase14/public/`, and
  `data/phase14/housing_observatory.sqlite`

## Governance

The interface publishes descriptive data, methods, and limitations. It does not
generate or publish narrative conclusions. New public analysis requires a named
human editor's approval, and the Phase 10 report remains on
`human_approval_hold`.

See [METHODOLOGY.md](METHODOLOGY.md), [DATA_DICTIONARY.md](DATA_DICTIONARY.md),
[LIMITATIONS.md](LIMITATIONS.md), and [RUNBOOK.md](RUNBOOK.md).
