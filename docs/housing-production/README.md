# Housing Production & Policy — Version 1.3

This release extends The Bay Outlook Housing Observatory with seven production- and policy-focused domains for Alameda, Contra Costa, Marin, Napa, San Francisco, San Mateo, Santa Clara, Solano, and Sonoma counties.

## What is included

- Annual 2018–2025 application, approval, entitlement, building-permit, completion, and ADU measures.
- Deterministic application-to-stage timelines with eligible, matched, and interval-specific sample counts.
- Sixth-cycle RHNA allocations compared separately with reported permits and completions for 2023–2025.
- Current sixth-cycle housing-element compliance records and county summaries.
- Statewide-zoning mapped-area composition and HCD-reported rezoning activity.

The verified public JSON is `data/phase14/production/public/housing-production-policy-data.json`. Normalized exports, the source-snapshot register, ten quality checks, and the SQLite warehouse live beside it under `data/phase14/production/`.

## Evidence boundary

This is a descriptive evidence product. Annual stages are not treated as one cohort, mapped zoning is not legal development capacity, and the release does not rank counties or calculate a policy score. New narrative analysis still requires named-human approval.
