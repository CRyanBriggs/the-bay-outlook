# Housing Analytical & Public-Use Layer

Version 1.5 is the cumulative public-use layer for the Housing Observatory. It preserves the four verified releases as separate, namespaced modules while making their evidence easier to inspect, compare, define, and download.

Start with `METHODOLOGY.md` for the integration rules, `DATA_DICTIONARY.md` for fields, `LIMITATIONS.md` for interpretation boundaries, and `RUNBOOK.md` for the review-only build workflow.
