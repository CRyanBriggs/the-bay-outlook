# Review-only runbook

1. Confirm the four inherited public payloads and their version/count contracts.
2. Run `build-phase14-public-use` to normalize, validate, and export the public-use layer.
3. Run the full repository test suite and `verify-phase14-public-use`.
4. Inspect all 16 quality checks and the manifest hashes.
5. Build and visually inspect the Site routes at desktop and mobile widths.
6. Confirm all downloads, definitions, source links, keyboard controls, and county/measure changes.
7. Review the exact public GitHub diff and Site checkpoint.
8. Publish only after explicit human approval, then record immutable commit and Site version evidence.
9. Rerun the verifier and full test suite before sealing the checkpoint.

The workflow never self-approves narrative analysis or changes the Phase 10 hold.
